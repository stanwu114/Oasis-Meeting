# Action 功能 v1:AI 分析 → 对话打磨 → 落地行动

## 核心流程(用户定义)
1. 选定一场会议(已导入纪要/转写稿)→ **AI 一次性分析出行动项 + 每项的具体思路建议**
2. 对初步建议不满意 → **与 AI 对话反复讨论**,方案随讨论实时更新,直到满意
3. 满意 →「确认方案」→ 落地为行动项,进入跟踪(待办/进行中/完成)

另保留:手动新建独立 Action(不强制关联会议);侧边栏按状态过滤;删除进统一回收站;设置左下角统一。

## 一、数据层(src/main/db.ts)
v6 迁移(SQLite user_version 5 → 6)建 `actions` 表:
`id / meeting_id(可空,不用 FK,会议删除后行动项保留) / title / detail(行动思路与执行建议) / status(todo|doing|done) / source(ai|manual) / created_at / updated_at / completed_at / deleted_at(软删除)`
CRUD:`listActions()`(LEFT JOIN pages 取会议标题,updated_at DESC)/ `createAction` / `updateAction`(status 变更写 completed_at)/ `trashAction` / `restoreAction` / `deleteActionPermanent` / `listTrashedActions`

## 二、LLM(src/main/llm.ts)
- `draftActionPlan(meetingName, summary, transcript)` → 初步方案 `PlanItem[]`({title ≤20字动宾结构, detail:具体思路建议——步骤/负责人/交付物/时限}),JSON 数组,正则+parse 兜底
- `reviseActionPlan(meetingName, summary, transcript, currentPlan, history, userMessage)` → **每轮输出 = 讨论回复文本 + `---PLAN---` 分隔符 + 修订后完整方案 JSON**;解析拆分,方案随对话实时刷新
- 落地后单条行动详情页保留轻量「AI 细化」按钮(基于会议上下文展开执行步骤)

## 三、IPC 契约(src/shared/ipc.ts + preload + src/main/ipc.ts)
- `actions` 域:list / create / update / trash / restore / delete-permanent / trash-list
- `ai` 域新增:`ai:plan-draft`(选会议后初步分析)、`ai:plan-revise`(对话修订)、`ai:action-refine`(落地后单项细化)
- 新类型 `ActionItem`(含 meetingTitle);MeetingPage 不加按钮,生成入口统一在 Action 模式

## 四、渲染层
1. **stores/actionStore.ts**(新):`actions / currentId / filter(all|todo|doing|done)` + 方案工作台状态 `planWorkbench:{meetingId, meetingName, summary, transcript, plan: PlanItem[], messages: {role,content}[], phase: idle|drafting|discussing}`(内存态,应用运行期间切视图不丢);init/refresh/select/create/update/trash/setFilter + 工作台动作(startDraft/sendMessage/updatePlanItem/removePlanItem/confirmPlan→批量入库/exitWorkbench)
2. **ActionSidebar.tsx**(新):「新建 Action」+「从会议生成方案」入口、状态过滤段(带计数)、行动项列表(状态圆点单击循环切换、标题、来源会议小字、选中高亮)
3. **ActionView.tsx**(重写)四态:
   - **方案工作台**(核心):顶部所选会议信息 + 重新选择;方案卡片区(每项标题+思路,可手动微调/删除条目);讨论对话框(消息流+输入框,AI 回复后方案区实时刷新);「确认方案,开始行动」→ 批量入库(source=ai)→ 跳列表;生成中/对话中显示占位动画
   - **手动新建**:标题+详情表单,可不关联会议
   - **详情模式**:标题/状态编辑、来源会议(点击跳回 Meeting,已删则禁用)、详情防抖保存、AI 细化、两段确认删除
   - **空态**:引导
4. **Sidebar.tsx**:`view === 'action'` 时主体换 ActionSidebar;底部回收站/设置不动
5. **TrashView.tsx**:分「会议页面」「行动项」两组,各自恢复/彻底删除,全部删除清空两组
6. **Icon.tsx**:新增 `check` 图标

## 五、边界与收尾
- 会议无纪要/转写稿 → 提示先完成转写或纪要;会议被删 → 行动项保留显示「会议已删除」;LLM 失败/未配 Key → toast 指向「设置 → AI 总结模型配置」;讨论方案确认前不落库
- CSS:状态点(空心灰/琥珀/绿勾)、方案卡片、对话框、会议选择列表
- typecheck + build + 重启验证

## 实施顺序
数据层 → LLM(draft/revise/refine) → IPC → actionStore → ActionSidebar/ActionView(工作台优先) → TrashView + Icon → 样式 → 构建重启
