# Notion Oasis — 本地优先的类 Notion 笔记 + 离线录音转写(macOS)

## 已确认的决策
- 转写模式:**先录后转**(录音时显示波形/计时,停止后本地一次性转写)
- 引擎:**SenseVoice Small**(经 sherpa-onnx-node 1.13.6,darwin-arm64 原生支持;中文字错率 ~8%,模型仅 ~230MB,内置 VAD + 标点,支持中英日韩粤)
- 范围:核心笔记(页面树 + 块编辑器 + 搜索 + 回收站 + 暗色模式)+ 录音转写
- 平台:仅 macOS(Apple Silicon)

## 技术栈
| 层 | 选择 |
|---|---|
| 桌面框架 | Electron + electron-vite(TypeScript 全栈) |
| 编辑器 | BlockNote(`@blocknote/react` + `@blocknote/mantine`,中文 i18n;自带 `/` 菜单、块拖拽、Markdown 快捷键) |
| 状态 | React 18 + zustand |
| 存储 | better-sqlite3(主进程,WAL 模式)+ 音频文件存 userData/media/ |
| 转写 | sherpa-onnx-node(主进程加载 SenseVoice int8,N-API 免重编译) |
| 录音/波形 | getUserMedia + MediaRecorder(webm/opus)+ fix-webm-duration + wavesurfer.js v7 Record 插件 |

## 数据库

## 核心流程

**录音**: 侧栏/编辑器录音按钮 → IPC 调 `systemPreferences.askForMediaAccess()`(Info.plist 已声明用途)→ getUserMedia + MediaRecorder,wavesurfer Record 插件实时波形 → 停止后 fix-webm-duration 修时长 → ArrayBuffer 发主进程存盘 + 建 recordings 行 → 自动触发转写,块内显示"转写中…"。

**转写(关键:无需 ffmpeg)**: 渲染进程用 `decodeAudioData` + `OfflineAudioContext` 把 webm/opus 解码并重采样为 16kHz 单声道 PCM(Int16 传输,1 小时约 115MB)→ IPC 发主进程 → 首次使用时模型管理器从 HuggingFace 下载 SenseVoice(model.int8.onnx ~230MB + tokens.txt,带进度条事件)→ sherpa-onnx OfflineRecognizer(language=auto, with_itn=true)转写 → 存 transcript、发完成事件 → 编辑器把文稿以带时间分段的段落块插入音频块下方。同一管线也支持导入本地 mp3/m4a/wav 文件转写。

**音频回放**: 主进程注册 `oasis-media://` 自定义协议流式读文件,自定义 BlockNote 块渲染 wavesurfer 播放器 + 转写状态/文稿。

## 实施步骤
1. **脚手架**: electron-vite + React + TS + ESLint/Prettier,主/渲染/preload 三层跑通,窗口与热重载
2. **数据层**: better-sqlite3 建表/migration、pages CRUD IPC、类型化 preload API、FTS5 搜索同步
3. **笔记 UI**: 侧栏页面树(新建/重命名/嵌套/拖拽排序/回收站/恢复)、BlockNote 编辑器 + 内容持久化 + 中文界面、Cmd+K 搜索弹窗、暗色模式
4. **录音**: 麦克风权限链路、录音面板(波形+计时)、webm 修复与存盘、oasis-media 协议、自定义 recording 块 + 播放器
5. **转写**: 模型下载管理器(进度 UI)、PCM 解码管线、SenseVoice 引擎服务、文稿插入与展示、导入文件转写、错误与重试
6. **收尾**: app 菜单、electron-builder 打包配置、README

## 已知风险与对策
- better-sqlite3 与 Electron ABI:锁定版本,必要时 `@electron/rebuild`;sherpa-onnx-node 是 N-API 稳定 ABI,理论免重编译(实现时验证,兜底方案是 spawn 独立 Node worker 跑引擎)
- WebM 无时长元数据 bug:已纳入 fix-webm-duration
- BlockNote 为 MPL-2.0:不修改其源码即无开源义务
- 全程离线:仅模型首次下载联网,之后转写零网络
